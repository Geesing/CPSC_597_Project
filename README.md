# English-Spanish Document Searcher
## To Install
Open `DocumentSearcher.command` from a file browser. Grant execute permissions if necessary.
# Dataset
The semantic searcher's chunking strategy was partly optimized by evaluating search performance on [Ferrero et al.'s Cross-Language Dataset.](https://aclanthology.org/L16-1657/). However, the original repository is no longer available. To replicate the evaluation process, clone the backup linked [here](https://github.com/Geesing/Cross-Language-Dataset.git) into the `data/` directory, then run `searcher_evaluation.ipynb`.
